# badge

![Version](https://img.shields.io/github/v/release/chaito10/badge)

A standalone SVG badge builder that works entirely in the browser.

## What is this?

badge is a self-contained HTML tool for creating SVG badges. It lets you pick a mode, enter left and right label text, choose colors, and preview the result before exporting the SVG markup. No build step or server is required; just open the file in any modern browser.

## Features

- Single-color and two-color (Shields-style) badge modes
- Live SVG preview
- Customizable label text and colors
- Portable, offline-friendly HTML file

## Install / Quickstart

Clone the repository:

```bash
git clone https://github.com/chaito10/badge.git
cd badge
```

## Usage

Open `index.html.html` in a web browser, configure the badge fields, and copy the generated SVG.
